Zephyrus 1.0.x is the first stable release of the local-first AI harness. It
ships the core workspace — chat, memory, research and documents — on a single
FastAPI server with Docker Compose as the supported deployment path.

## What shipped in 1.0

- Chat with streaming responses and tool calls.
- Long-term memory backed by a local vector store.
- Multi-source research through SearXNG.
- Document upload, parsing and retrieval.
- Local model runtimes through Ollama and OpenAI-compatible endpoints.

## Install

```bash title="Terminal"
git clone --branch v1.0.1 https://github.com/yash-dev007/Zephyrus
cd Zephyrus
cp .env.example .env
docker compose up -d --build
```
